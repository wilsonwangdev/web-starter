# 设计约定

界面方向是安静、清晰、可立即操作。参考 [Geist 的字体与颜色层次](https://vercel.com/geist/introduction)以及 [Linear 对导航和内容权重的处理](https://linear.app/now/behind-the-latest-design-refresh)，使用自己的布局与视觉变量，不复制品牌素材。

- 首页说明用途并提供一项主要操作，返回后可继续已有内容。演示流程真实可用，不伪造历史、模型响应或成功状态。
- `src/design-tokens.css` 集中定义颜色、字体、字号、间距、圆角与动效。组件使用语义变量；新增配色同时维护亮暗对照，不在组件内硬编码颜色。
- 默认用留白、对齐和文字层次组织内容。装饰不抢主要操作，不逐个功能堆卡片、渐变或发光效果。
- 交互控件使用原生语义和可访问名称。基础 Button、Dialog 和 Select 来自本仓库的 shadcn Radix 源码包；弹窗保留焦点约束、Esc 关闭和焦点返回。密度使用 Select，其余少量并列选项保留单选按钮。
- 语言资源集中维护，日期按当前语言格式化。处理长译文、空状态、保存失败、损坏记录和安装不支持状态，不只设计默认成功页。
- 布局随内容收缩，手机主要操作无需横向滚动；触控区域不因紧凑模式变得过小。弹窗有可滚动内容，工作区考虑安全区与软键盘。
- 同时检查亮暗、两种语言、主题与强调色组合、键盘焦点和减少动态效果偏好。行为测试与截图用于发现问题，真实手机体验另行验收。

视觉调整优先改变量或共享组件；需要例外时在代码中就近解释用途，避免另建重复的设计标准。

## 首屏与启动

HTML 先显示与页面结构衔接的中性骨架，样式独立于应用脚本到达，亮暗模式沿用绘制前初始化。正常加载不显示宣传文案或伪造进度，不设置最短等待；减少动态效果时骨架保持静止，高对比模式保留轮廓。应用就绪立即接管，禁用脚本时隐藏骨架并给出说明。

入口或应用模块失败时停止展示加载状态，提供手动重新加载入口，保留浏览器中已保存的内容；不自动刷新循环。验证时延迟实际应用模块观察首帧与交接，并分别覆盖失败恢复、手机宽度、语言和主题。

## 基础组件与主题

`packages/ui/` 维护基础交互与样式，通过 `@web-starter/ui/components/<组件>` 使用。组件不拥有语言、偏好或草稿状态，翻译与设置值由应用提供；[上游来源和本地适配](licenses/shadcn-ui.md)随代码维护。

组件样式使用 `ui:` 前缀并显式扫描包源码，不引入 Preflight。全局样式统一由 `src/index.css` 按设计变量、组件包、应用样式的顺序导入，不从组件内抢先引入应用全局样式。颜色、字号、字体和主题值继续以 `src/design-tokens.css` 为准，样式桥接不复制一套品牌值。样式按 `theme → base → components → utilities → app` 分层：全局重置放在 `base`，应用特定样式放在 `app`，避免重置覆盖基础组件的颜色和边框。`body` 字体覆盖正文和挂载到页面外层的弹窗；调整样式层级时同时核对字体、弹层位置、安全区与高对比模式下的焦点轮廓。

按钮默认不提交表单，提交动作显式指定 `type="submit"`；链接通过 `asChild` 保留原生链接语义。嵌套 Select 的第一次 Escape 只关闭选项，随后关闭 Dialog 并返回打开它的入口。新增控件保持触控尺寸、长译文、亮暗与减少动态效果支持。

## 可选设计辅助

视觉审查或改版先记录真实页面、代表状态与截图，再确定修改范围；完成后对照检查并运行项目既有验收。设计依据继续由本页和设计变量维护，外部技能的诊断逐项核实，检查分数不能代替交互与多设备验证。

[Hallmark](https://www.usehallmark.com/) 可按需用于设计审查或改版。先让它读取本页与现有变量；应用界面采用其 `app screen` 范围，框架项目通过真实服务路由检查，保留组件职责、路由、数据流、多语言、主题及测试标识。其渲染工具需要额外浏览器依赖，按上游说明配置；本模板的提交检查和 CI 继续使用项目自身工具。

需要时在项目目录安装，默认不修改全局技能：

```sh
npx skills add nutlope/hallmark --skill hallmark --agent codex --copy
```

安装会写入 `.agents/skills/hallmark/` 和 `skills-lock.json`。在主题分支审查上游内容、许可与来源记录，再决定是否提交；未指定固定引用时，内容摘要不代表锁定上游提交。后续用 `npx skills update hallmark --project` 更新，同样需要审查改动和验证实际效果。模板不附带上游副本，不自动安装或更新；`.hallmark/` 中的过程记录与截图保留在本地。
